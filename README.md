## ⚡ Asynchronous Python Basics

Asynchronous programming allows Python to handle tasks without blocking while waiting for operations such as network requests or file-related I/O.

**Topics I'm Learning:**
- Synchronous vs. Asynchronous Programming
- `async` and `await`
- Coroutines
- Event Loop
- Tasks and `asyncio`
- Running Multiple Tasks Concurrently
- Basic Performance Improvements

### Example

```python
import asyncio

async def greet():
    print("Hello!")
    await asyncio.sleep(2)
    print("Welcome to Python!")

asyncio.run(greet())
```
